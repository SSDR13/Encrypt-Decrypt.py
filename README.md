

### 🔐 ED APP - Text Encryption & Decryption GUI

A simple Python GUI application built using **Tkinter** that allows users to **encrypt** and **decrypt** text using a base64 encoding scheme. The application uses a **password-based access system** to perform encryption and decryption, ensuring that only users with the correct key can access the functionality.

---

### 📌 Features

* 🔏 Encrypt plain text using Base64
* 🔓 Decrypt encoded Base64 text back to plain text
* 🔑 Password-protected encryption/decryption (default password: `1234`)
* 🧼 Reset button to clear input fields
* 📋 Clean and user-friendly interface using Tkinter

---

### 🛠️ Tech Stack

* **Python 3**
* **Tkinter** – for GUI
* **base64** – for encoding/decoding
